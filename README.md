# Shortly - URL Shortener Service

> 만료/비밀번호/통계 기능을 제공하는 URL 단축 서비스

## 🛠 기술 스택

- **Language**: Java 21
- **Framework**: Spring Boot 3.5.x
- **Persistence**: Spring Data JPA, Hibernate, Querydsl
- **Database**: MySQL 8
- **Cache**: Redis 7
- **Security**: Spring Security, JWT, Bucket4j
- **Frontend**: React, TypeScript
- **Build**: Gradle (Kotlin DSL)
- **Test**: JUnit 5, Mockito, k6
- **Infra**: Docker Compose, GitHub Actions

## ✨ 주요 기능

- URL 단축 및 리다이렉트
- 회원 가입/로그인 (JWT 기반 인증)
- 만료 시간 / 비밀번호 보호 옵션
- 내 링크 관리 (목록, 수정, 삭제)
- 클릭 통계 (총 클릭 수, 일별 클릭 수)
- QR 코드 생성
- 악성 URL 차단 (Google Safe Browsing API)
- Rate Limiting
